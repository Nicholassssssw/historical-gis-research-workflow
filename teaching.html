逐步理解八個研究階段的目的、資料準備、判斷原則與成果檢查方法。

◆

如何使用這套工作流程

八個步驟由文本處理開始，逐層加入歷史區域、地方志、資料庫及空間推算證據，最後才製作地圖。每一步均應保留 Prompt、輸入資料、人工修改與輸出檔案。

證據優先只按文本、地方志及可追溯資料來源作判斷，不以模型記憶補充。
逐層縮窄先確認古今區域及座標範圍，再進行精確座標配對與推算。
保留不確定性確認、可能及資料不足必須分開標示，避免把推算誤作已證實位置。
壹

抽地名

  • 目的：找出文本中具有研究價值的地理實體。
  • 準備：提供文本名稱、年代、日期段與完整原文。
  • 檢查：核對原句、日期及經過／提及狀態，避免遺漏引文地名。
查看 Prompt 與成果
貳

配對古代與現代地區

  • 目的：建立歷史府州縣與現代行政區的對照。
  • 準備：使用旅行年代、同日行程及文本明示的行政界線。
  • 檢查：不得只因現代位置接近便取代歷史行政歸屬。
查看 Prompt 與成果
叁

配對地方志距離資料

  • 目的：尋找方向、里程、鄉里及相鄰地點證據。
  • 準備：以地名、歷史府縣及相關年代搜尋地方志。
  • 檢查：分清原志記載、後人轉引與研究者推論。
查看 Prompt 與成果
肆

設定經緯度範圍

  • 目的：為候選地點限定合理的空間搜尋邊界。
  • 準備：結合歷史區域、前後站、方向及里程。
  • 檢查：記錄範圍設定原因，不用縣治座標冒充具體地物。
查看 Prompt 與成果
伍

Database 及 API 配對

  • 目的：比較歷史與現代資料庫中的候選座標。
  • 準備：使用規範地名、年代、歷史／現代行政區及座標範圍。
  • 檢查：保留來源、候選名稱、分數與人工選擇紀錄。
查看 Prompt 與成果
陸

地方志座標推算

  • 目的：處理資料庫未能直接定位但地方志證據較完整的地點。
  • 準備：整理參照點、方向、距離及行政歸屬。
  • 檢查：標示推算方法與誤差範圍，不表述為唯一精確位置。
查看 Prompt 與成果
柒

原文座標推算

  • 目的：利用作者路線語境估計剩餘地點的相對位置。
  • 準備：提取前後實際行程地點、方向詞及距離詞。
  • 檢查：文本先後不等於地理鄰近；沒有空間證據便維持資料不足。
查看 Prompt 與成果
捌

ArcGIS 地圖呈現

  • 目的：把確認及推算結果轉化為可檢查的空間展示。
  • 準備：輸出 WGS84 經緯度、來源、分類、原句及路線次序。
  • 檢查：用不同符號區分確認與推算座標，並註明路線不是歷史道路重建。
